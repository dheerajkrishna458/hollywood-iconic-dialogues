# The Shining (1980)

> "Here's Johnny!"

| | |
|---|---|
| **Character** | Jack Torrance |
| **Actor** | Jack Nicholson |
| **Director** | Stanley Kubrick |

**Context:** Jack leers through a bathroom door he has just hacked open with an axe.

**Why it endures:** It borrows the Tonight Show's famous host introduction and turns it into pure horror.
